# Tamagotchu

A browser-based interactive Tamagotchi-inspired project. The page combines video interactions, a RiveScript chatbot, a score counter, and retro screen styling.

## Contents

- `index.html` - main page structure.
- `style.css` - layout and visual styling.
- `scripts/video.js` - video interaction controls.
- `scripts/script.js` - RiveScript chatbot setup.
- `scripts/score.js` - counter interaction.
- `brain/` - chatbot brain files.
- `media/` and `wrapper-media/` - video and image assets.

## Run

Serve the project locally:

```bash
python3 -m http.server 5500
```

Open `http://127.0.0.1:5500/`.

## Git Notes

Large media assets are tracked with Git LFS.
